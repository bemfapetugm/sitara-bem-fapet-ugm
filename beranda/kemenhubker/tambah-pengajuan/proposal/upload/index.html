Panduan Unggah Dokumen

  • Gunakan format Word (.doc/.docx)
  • Ukuran maksimal 10 MB per dokumen
  • Pastikan dokumen jelas, tidak buram, dan lengkap
  • Nama file disarankan sesuai isi dokumen
  • Dokumen wajib harus diunggah sebelum dapat melanjutkan
  • Anda dapat mengganti file jika terjadi kesalahan unggah
!

Dokumen Wajib
